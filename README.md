# Transcribble

A standalone transcription app that maps Ethiopic script (Ge'ez, Amharic and Tigrinya), Arabic, or Syriac script (Aramaic and Classical Syriac) to Hebrew without vowel marks.

Download the repository as a ZIP from GitHub, extract it, and open `index.html` in a browser. No installation or server is required. Choose the actual source language and direction, type or paste text, and copy the result. For Ethiopic, independently choose the etymological Ge'ez or modern Amharic mapping; neither is a complete Tigrinya-specific mapping. Switching languages or directions keeps the input intact; the sample button loads a sample for the selected mode. The interface is in Hebrew.

The Ethiopic mapping follows the supplied consonant table. The Arabic mapping is character-based: it removes Arabic vowel marks, shadda and tatweel, but retains letters such as alif, waw and ya, which may represent long vowels. It maps ta marbuta to ה and alif maqsura to א. The Syriac mapping uses the 22 basic letters and removes Syriac combining marks, including consonantal pronunciation marks; matres lectionis remain as letters. Arabic and Ethiopic punctuation are converted, and unsupported characters are left unchanged. This is a transcription aid, not translation or a complete linguistic transcription; consonant distinctions may use Hebrew marks such as shin dots, dagesh, and geresh.

In the forward direction, clickable words below the output show possible initial prefixes separately (Ge'ez ወ, ለ, በ or Arabic و, ل, ب). This is a visual heuristic, not morphological analysis: it can mark part of a root as a prefix and does not change the copied text.

Each clickable transcription shows its original word beneath it. The dictionary selector resets to a language-specific default when the source language changes. Amharic defaults to AmharicPro, with Amharic and English Wiktionary as alternatives. Tigrinya and Arabic default to their respective Wiktionary editions, with English Wiktionary as an alternative. Ge'ez, Aramaic and Classical Syriac currently offer English Wiktionary only; it is an English-interface multilingual dictionary, not a dedicated dictionary for those languages.

Clicking a word sends the original spelling to the selected dictionary and requires an internet connection. Language-specific sites open in a new tab; if the browser blocks it, use the displayed link. For English Wiktionary, the app checks only the selected source-language section, shows up to five English definitions, extracts explicitly marked Arabic roots and Hebrew or Arabic cognates when available, and links to the full entry. Arabic vowel marks are removed for lookup; if a pointed Syriac word is missing from English Wiktionary, its unpointed form is also tried. The Aramaic option looks for an Aramaic section, whereas the Classical Syriac option looks for a Classical Syriac section; the same Syriac-script spelling may occur under one but not the other. Cognates are not necessarily translations; not all entries contain these fields, and the limited extraction does not cover every Wiktionary format. Entries are attributed to [Wiktionary](https://en.wiktionary.org/) and its contributors; see its [terms of use](https://foundation.wikimedia.org/wiki/Policy:Terms_of_Use).

Reverse transcription is approximate, not a reconstruction: it chooses one form where multiple source letters or vowels correspond to the same Hebrew spelling. For Ethiopic it uses the sixth order, so the result may not occur in a source text. Unsupported characters are preserved. Dictionary lookup and prefix highlighting are available in the forward direction only.
